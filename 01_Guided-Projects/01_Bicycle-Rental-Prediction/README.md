# Predicting Bicycle Rental
This project was published by the University of London in the Coursera platform.

The course materials will not be entirely uploaded and the current repository will only present the documentation of the project.

## Scope of the Project
Predict the number of bicycles or demands will be requested for rental on a given day depending on different weather conditions.
The data used is based on Washington DC.

## Procedure
To complete the project, I followed the following procedure:
1. Data Preparation
2. Exploratory Data Analysis
3. Feature Engineering
4. Model Development
5. Model Refinement
5. Conclusion

## Phases
- Problem Definition
- Gathering of Data
- Data Preparation
- Data Exploration and Learning
- Eventual redoing the data preparation
